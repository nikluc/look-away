# Look Away

A first-person horror prototype. A hand comes out of the dark and points. Look any other way, but only after it points. Turn too soon, too late, or the same way, and she takes you.

**Play in the browser:** https://nikluc.github.io/look-away/ (desktop browser recommended; the first load is about 140 MB)

- Arrow keys / WASD to look
- PLAY ONLINE: up to 10 players per lobby, last one standing. Create a lobby and share the 4-letter code.
